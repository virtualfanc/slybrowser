# License and billing support

Use the support link on the official SlyBrowser website for account, payment, license, download, or feedback requests. Do not post license files, payment records, access tokens, private keys, or full diagnostic archives in public issues.

Include only what support needs:

- account email or order reference;
- affected plan and platform;
- UTC time of the failure;
- public error code from `contracts/error-codes.json`;
- a short reproduction description with secrets removed.

SlyBrowser support may ask for a sanitized diagnostic bundle through an authenticated channel. License delivery and entitlement changes occur only after server-side verification. Email provider configuration, credentials, queues, templates, retention, and operator commands are private service concerns.

Security reports follow [SECURITY.md](../SECURITY.md). Public product feedback belongs in the official feedback channel and must not include sensitive account data.
