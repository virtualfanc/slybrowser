# Plans and licensing

## Installation

Licensing is built into the authorized SDK flow; there is no separate private key or
server implementation source package for users.

## Configuration

Canonical plans are Free, Basic, Pro, Max, and Ultra. Prices, concurrency, renewal, and
feature grants come from the public plan contract rather than duplicated examples.

## API and example

The SDK requests authorization and runtime entitlement, then enforces the signed result
through the Browser and project WebDriver handoff.

## Errors

Expired, revoked, tampered, over-concurrency, or incomplete authorization fails closed.

## Limitations

Local fixtures do not prove production billing, entitlement delivery, renewal, or
revocation behavior.

## Platforms

The entitlement is not permission to substitute another platform or release Artifact.
