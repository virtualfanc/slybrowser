# Detection QA

## Installation

Detection runners are development and release-QA tools, not part of a normal user
installation.

## Configuration

Record test date, tested Artifact identity, configuration, source page, scoring method,
and known limitations.

## API and example

Run only authorized QA targets and retain the raw result separately from the public
summary. Compare products using documented legitimate configurations.

## Errors

Unavailable, manual, blocked, inconclusive, pass, and fail are distinct outcomes. A
missing live result is never converted to pass.

## Limitations

Detection results are reproducible product QA, not a promise to bypass access controls,
challenges, or abuse protection.

## Platforms

Results apply only to the dated tested Browser, configuration, target, and platform.
