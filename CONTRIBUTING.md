# Contributing

SlyBrowser is currently developed in a private repository. Before submitting a change:

1. Open or reference an issue describing the user-visible outcome.
2. Keep private Chromium source and binary artifacts outside this repository.
3. Add tests for behavior changes and update shared contracts when public options change.
4. Run formatting, unit, contract, and relevant browser integration tests.
5. Preserve third-party copyright and license notices.

Contributions are licensed under the repository's MIT License unless another written
agreement is made before submission. Do not submit code, assets, or datasets you are not
authorized to contribute.

Security reports follow [SECURITY.md](SECURITY.md), not the public issue tracker.
