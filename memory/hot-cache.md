# SlyBrowser hot cache

Updated: 2026-08-16

## Durable commercial facts

- The public SDK, schemas, scripts, tests, and documentation are MIT-licensed; the
  distributed browser binary is a separate proprietary deliverable.
- The planned signed lease includes feature, browser-version, device, and session
  claims, so maximum active browser sessions are the natural primary entitlement.
- Browser execution currently occurs on customer infrastructure. Local browser hours
  and customer-owned profiles are not vendor cost drivers.
- A production license service, protected signer, revocation/concurrency authority,
  final binary terms, and release clearance are still preconditions for paid release.
- Current business-model recommendation: free one-session Developer entitlement;
  paid concurrency tiers; separate Enterprise offline/LTS and OEM/SaaS rights; optional
  managed cloud later with usage pricing.
- CloakBrowser moved from gating the current binary behind Pro in 0.4.0 to offering the
  same latest browser and core features free at one concurrent session in 0.5.0/current
  pricing. Its paid differentiation is now concurrency (5/20/200/2,000), support, and
  separate Enterprise/Cloud/OEM rights—not weakened browser quality.
- Source report: `docs/business-model-research-2026-08-15.md`.
- Focused Cloak relationship analysis:
  `memory/research/competitor-analysis/2026-08-16-cloakbrowser-business-model-feature-relationship.md`.
- Approved public promotional pricing: Launch 5/$19, Studio 20/$49, Fleet 200/$199,
  and Grid 2,000/$499 per month. The four paid package names are SlyBrowser-specific;
  the concurrency anchors and promotional ceilings match CloakBrowser's public page
  measured on 2026-08-16. The one-process free entitlement is not a fifth pricing
  card. Decision source:
  `memory/research/competitor-analysis/2026-08-16-slybrowser-pricing-alignment.md`.
- SlyBrowser's commercial differentiation is the version-matched project W3C
  WebDriver, strict native profile contract, signed lease/release trust design and
  reproducible evidence. Delivery, production licensing and supported-release gaps
  prevent public checkout today.
- Public CloakBrowser feedback collected on 2026-08-16 clusters around coherent
  fingerprint behavior, fail-closed proxy routing, CDP/persistent-context reliability,
  exact version delivery, Humanize compatibility and binary supply-chain trust. These
  are discovery signals, not confirmed defect prevalence. Proposed requirements:
  `memory/research/competitor-analysis/2026-08-16-cloakbrowser-issues-reddit-requirements.md`.
- The saved paired 40-entry comparison is SlyBrowser 148 at 75.73 versus stock
  Chromium/Playwright 153 at 72.11 coverage-adjusted. Different browser majors make it
  directional evidence, not strict TLS/fingerprint parity evidence.
- A weighted public-launch gate audit scores 54.25/100: the package and entitlement
  foundation exist, while account-bound billing reconciliation, production enforcement,
  signed production delivery, operations and legal gates remain incomplete. A manually
  operated private preview is viable; public self-serve checkout is not.
