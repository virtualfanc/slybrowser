# Community conduct

Project discussions should be professional, technically focused, and welcoming.
Harassment, threats, discriminatory conduct, doxxing, publication of secrets, and
deliberate disruption are not accepted in project spaces.

Report conduct concerns privately to the repository owner. Maintainers may edit or
remove content and restrict participation when necessary to protect contributors and
users. Good-faith technical disagreement, security research, and evidence-based review
are welcome when handled respectfully.
